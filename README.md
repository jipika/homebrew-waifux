# homebrew-waifux

Homebrew Cask for [WaifuX](https://github.com/jipika/WaifuX) — a beautiful anime wallpaper and content browser for macOS.

## Installation

```bash
brew tap jipika/waifux
brew install --cask waifux
```

## Upgrade

```bash
brew upgrade --cask waifux
```

## Uninstall

```bash
brew uninstall --cask waifux
```

## Auto-Update

This tap is automatically updated whenever a new release of WaifuX is published on GitHub.
